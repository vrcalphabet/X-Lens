# X-Lens

**覗くと、もう一枚。**

X（旧Twitter）に投稿する画像に、もう一枚の画像を隠せるツールです。見た目は普通の画像ですが、X-Lens のレンズを重ねた人にだけ、隠された画像が見えます。

- Webアプリ：画像を隠す・保存した画像を覗く
- Chrome拡張機能：Xのタイムライン上で、そのままレンズを重ねて覗く

## できること

### Webアプリ

- **画像を隠す**：表に見せる画像（表画像）と、隠したい画像（裏画像）を選ぶだけで、X にそのまま投稿できる PNG を作れます
- **レンズの大きさを決める**：覗く人が使えるレンズの大きさの範囲を、作る側で決められます
- **合言葉**：合言葉を知っている人だけが裏画像を見られるようにできます
- **コピーの禁止**：拡張機能の右クリックメニューから裏画像をコピーできないようにできます（初期設定でオン）
- **覗く**：保存した画像や X から持ってきた画像を開いて、レンズで確認できます
- ブラウザの中だけで動きます。画像をサーバーに送ることはありません。アプリとしてインストールすれば、オフラインでも使えます

### Chrome拡張機能

- 画面右下のボタンでレンズモードをオンにすると、X-Lens の画像に金色の枠が付きます（合言葉付きは紫色）
- 画像にマウスを乗せると、レンズ越しに裏画像が見えます。ホイールでレンズの大きさを変えられます
- 合言葉付きの画像は、クリックして合言葉を入れると見られます。解除した合言葉はその端末に保存されます
- 右クリックメニューから、元のサイズの画像（表画像・裏画像）をコピーできます
- Chrome と Edge に対応しています

## 使い方

1. Webアプリの「画像を隠す」で、表画像と裏画像を選びます
2. レンズの大きさなどを調整して、PNG を保存します
3. **PC のブラウザから**、保存した PNG をそのまま X に投稿します
4. 見る人は、拡張機能のレンズモードをオンにして画像にマウスを乗せます。拡張機能がなくても、画像を保存して Webアプリの「覗く」で開けば見られます

> [!IMPORTANT]
> - 画像を切り抜いたり編集したりすると、隠した画像は読めなくなります
> - PC ブラウザ以外（スマホアプリなど）からの投稿は確認していません
> - 防げるのは拡張機能からのコピーだけです。スクリーンショットは防げません
> - X の仕様が変わると、予告なく使えなくなることがあります

## 仕組み

X は、長辺 900px 以下で透過ピクセルを含む PNG を、変換せずにそのまま配信します。X-Lens はこれを利用しています。

- 画像を長辺 896px に高画質縮小し、右下の 1 ピクセルだけを半透明（Alpha = 254）にします
- 裏画像を JPEG に圧縮して、表画像の RGB の最下位 1 ビットに埋め込みます。表画像の変化は各色 ±1 階調だけです
- 先頭のヘッダーに、画像の大きさ、レンズの大きさの範囲、合言葉の有無、コピー禁止の設定と、CRC を入れています。1 ビットでも壊れていれば「裏画像なし」として扱います
- 合言葉を設定した場合は、裏画像を AES-256-GCM で暗号化します。鍵は合言葉から PBKDF2-SHA256（60万回）で作ります
- タイムラインの縮小された画像からでも X-Lens の画像だと分かるように、縮小や JPEG 再圧縮に強い目印（存在マーク）を入れています。拡張機能はこの目印で金色の枠を付け、元のサイズの画像はマウスを乗せたときにだけ取得します

## 開発

Node.js 20.19 以上（または 22.12 以上）が必要です。

```sh
npm install

# Webアプリ
npm run dev        # 開発サーバー（http://localhost:8192）
npm run build      # dist/ に出力
npm run preview    # dist/ をローカルで確認

# Chrome拡張機能
npm run dev:ext    # 開発用（HMR、http://localhost:5174）
npm run build:ext  # extension/dist/ に出力
```

拡張機能は、`chrome://extensions`（Edge は `edge://extensions`）でデベロッパーモードをオンにし、「パッケージ化されていない拡張機能を読み込む」で `extension/dist` を選ぶと使えます。

Webアプリは静的なファイルだけで動くので、`dist/` を HTTPS の静的ホスティングに置けば公開できます。

### 構成

```
index.html              Webアプリの画面
src/
  main.js               画面の制御
  ui/lens.js            レンズ表示
  core/codec.js         埋め込み・読み取り・暗号化
  core/mark.js          存在マーク
  styles/app.css        スタイル
extension/
  manifest.config.js    拡張機能の manifest
  popup.html            ツールバーのポップアップ
  src/content.js        X の画面上の処理（ボタン、枠、レンズ、右クリックメニュー）
  src/background.js     画像の取得、右クリックメニュー
```

`src/core/` は Webアプリと拡張機能で共通です。
